# True-Cost-Accounting-of-bovine-meat-production-systems
This repository contains the complete data used for the paper "True Cost Accounting of bovine meat production systems across environmental, livelihood, health, and animal welfare dimensions" by Adèle Soulier, Gino Baudry, Agathe Crosnier and Idriss Komi. The data are provided in the Excel file TCAF-bovine-meat-data.xls.
